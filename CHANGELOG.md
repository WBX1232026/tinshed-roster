# Changelog

All notable changes to the Tinshed Roster project are documented here.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.1.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [1.0.0] - 2026-09-30

### Added

- Volunteer records: create, find, update, deactivate (#1, #2, #3)
- Productions and performances with dates and start times (#4, #5)
- Chronological performance listing (#6)
- Per-performance crew calls with roles and numbers needed (#7, #8)
- Assignments defaulting to "unconfirmed", change and remove (#9, #11)
- One-role-per-performance rule with automated tests (#10)
- Roster gap view showing filled and open positions (#12)
- Volunteer personal view of their own assignments (#13)
- SQLite snapshot persistence and CSV seed data (#14)
- Command-line entry point with demo walkthrough (#14)
